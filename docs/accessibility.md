# Accessibility

Ant Design supplies control and overlay behavior. Techosoul adds semantic tokens,
visible focus, named icon buttons, keyboard resize sliders, numeric alternatives
to range dragging and text accompanying financial/status colors. Providers scope
theme variables to overlays. Public documentation keeps native anchor navigation.

Run unit tests and Playwright/axe checks in all supported theme/density modes.
Existing CRM checks cover modal focus restoration, table scrolling, resizing,
mobile touch targets and selected contrast scenarios. New checks cover public
navigation, financial display and the packed consumer. These targeted automated
checks are not full WCAG certification. Screen reader/manual cross-browser,
zoom, high contrast and localization reviews remain release work.
